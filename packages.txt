# Deux formats acceptés :
#

#        https://raw.githubusercontent.com/<orga>/<repo>/<branche>/PKGBUILD
#
#   2) Un chemin relatif au dépôt :
#        packages/mon-outil/PKGBUILD
#
# Les dossiers packages/<nom>/ qui contiennent un PKGBUILD sont détectés
